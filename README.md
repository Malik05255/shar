# الشرطي

تطبيق أندرويد عربي لمحادثة صوتية مباشرة مع شخصية كلب شرطي تفاعلية.

## تجربة النسخة الحالية

- يفتح التطبيق مباشرة على مشهد الشرطي، بدون شاشات إعداد أو دردشة نصية.
- يطلب إذن الميكروفون ثم يبدأ التحية والاستماع تلقائياً.
- التعرف على الكلام مضبوط على `ar-SA` ويستخدم النتائج الجزئية لتقليل الإحساس بالتأخير.
- قائمة النقاط العلوية تبدّل بين **الإنترنت** و **بدون إنترنت**.
- وضع بدون إنترنت لا يتظاهر بالعمل: إذا لم يكن في الجهاز تعرف/صوت عربي محلي، يظهر تنبيه بدل الرجوع سراً إلى الشبكة.
- شخصية الشرطي لها قواعد مستقلة تمنع التهديد بالسجن، ادعاء إرسال دورية، أو طلب بيانات الطفل.
- يمكن لمس الشخصية أثناء كلامها لإيقاف الرد والعودة للاستماع.

## البنية

الموديول المنتج الوحيد هو `police-app`. مجلدات VibeApp القديمة باقية في المستودع كمرجع مؤقت لكنها غير مدخلة في Gradle ولا تُبنى مع التطبيق.

```text
Microphone
  -> Speech recognizer
  -> PoliceBrain
  -> Arabic TTS
  -> Character state / mouth animation
  -> Listen again
```

التفاصيل وخطة الانتقال إلى Qwen + STT/TTS عصبي + شخصية GLB/Filament موثقة في `docs/alshurti.md`.

## البناء

```bash
./gradlew :police-app:assembleDebug
./gradlew :police-app:testDebugUnitTest
./gradlew :police-app:lintDebug
```

> الشخصية المرسومة حالياً هي fallback متحرك وخفيف وليست بعد مجسم GLB فوتورياليستي. كذلك محرك الرد المحلي الحالي baseline آمن وليس Qwen بعد. الهدف من هذه المرحلة تثبيت دورة المكالمة والواجهة قبل إدخال ملفات النماذج الثقيلة.
