# ALMI_AI

ALMI_AI is a focused Android virtual try-on app.

## Current flow

1. Capture or select a person photo.
2. Paste a product URL or select a garment image.
3. Generate a realistic AI try-on image through OpenRouter.
4. Optionally generate a short outfit video.

## Android identity

- Application ID: `com.almi.ai`
- App label: `ALMI_AI`
- Languages: Arabic and English
- Arabic layout: RTL
- English layout: LTR

## Updates

CI assigns an increasing Android `versionCode`. Debug artifacts produced by the same ALMI_AI signing channel can be installed over the existing ALMI_AI app without uninstalling it first.
